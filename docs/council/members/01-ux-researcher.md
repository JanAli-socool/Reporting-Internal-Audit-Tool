# Principal UX Researcher

## P1
The demo asks "report in minutes?" but opens like a generic BI page. Viewers decide in the first 20 seconds; the report must appear above the fold.

## P2
Red controls next to red deltas create false alarms in a recording. Fix it.

## P3
Non-analysts don't read "pp". Grey for ticket volume is correct: more tickets is neither good nor bad.

## P4
The highest-risk item. An interviewer who spots a "contradiction" stops trusting every number. It must be resolved, not just captioned.

## P5
Trust is the thesis. Make the check visible and countable: "14 of 14 figures matched".

## P6
The audience watches a laptop recording. Mobile is a non-goal for this milestone.

## P7
Low priority. Nobody judges a prototype by its logo, but an emoji favicon does read as "template".

## P8
A silent 10-second wait is where demos lose people. Show progress.
